# Design canvas sources

Source files of the "Gym Tracker Screens" design canvas:
https://claude.ai/artifact/G6rHV4UL5Ae1fx6HbzLnnD (private to its owner unless shared).

- `project/canvas.json` lists the artboards and where each sits on the canvas.
- `project/*.dc.html` is one artboard each: a self-contained page with inline styles.

The canvas is the published copy of these files. Edits made on the canvas
itself are not written back here, so re-download before changing a file that
was edited there.
